## Story
**As a** developer
**I want** a LangGraph state graph configured with all workflow nodes
**so that** I can orchestrate the query pipeline

## Acceptance Criteria
1. LangGraph installed and imported (`langgraph` package)
2. State graph created with 5 nodes: QueryUnderstanding, VectorSearch, GraphTraversal, ContextConstruction, ResponseGeneration
3. Graph state schema defined: `{user_query, query_embedding, query_intent, vector_results, graph_results, context, response}`
4. Node execution order: QueryUnderstanding → VectorSearch → GraphTraversal → ContextConstruction → ResponseGeneration
5. Each node implemented as async function accepting state and returning updated state
6. Graph compiled and ready for invocation
7. Basic end-to-end test: Pass dummy query through graph, verify all nodes execute

## Dev Notes

### Source Tree Context
From `docs/architecture/source-tree.md`:
- **LangGraph files location**:
  - Main graph definition: `app/agents/graph.py`
  - Node implementations: `app/agents/nodes/` directory
  - Each node in separate file: `query_understanding.py`, `vector_search.py`, etc.
- **Dependencies**: Configured in `app/dependencies.py` with `create_rag_workflow()` function
- **Service integration**: `app/services/langgraph_service.py` will invoke the compiled workflow

### Tech Stack Context
From `docs/architecture/tech-stack.md`:
- **LangGraph version**: `0.0.60+`
- **LangChain version**: `0.1.0+` (dependency for LangGraph)
- **Purpose**: StateGraph for RAG workflows with built-in state management
- **Key features**: Conditional routing, debugging/visualization tools

### Components Context
From `docs/architecture/components.md`:
- **GraphRAGState schema**: Use Pydantic BaseModel (NOT TypedDict) for runtime type safety
- **Required fields**: `user_query: str`, `user_id: str`
- **Optional fields**: `intent`, `entities`, `vector_results`, `graph_context`, `constructed_context`, `final_response`, `metadata`
- **Validators**: Add `@validator` for intent validation and query non-empty check
- **Node return pattern**: Return dict with partial updates (LangGraph merges into state)
- **Error handling**: Wrap nodes to catch ValidationError and log failures

### Critical Implementation Notes
1. **Use Pydantic, not TypedDict**: Provides runtime validation, catches typos immediately
2. **State validation**: Configure `extra="forbid"` to catch field name typos
3. **Node stubs**: Each node should log entry/exit for debugging
4. **Async functions**: All nodes must be `async def` for FastAPI compatibility
5. **State updates**: Nodes return dict, not full state object (LangGraph pattern)

### Testing
From `docs/architecture/10-test-strategy.md`:
- **Test location**: `tests/integration/test_langgraph_workflow.py`
- **Test framework**: pytest with pytest-asyncio
- **Test approach**: End-to-end integration test with dummy data
- **Fixtures needed**: None for this story (workflow is self-contained)
- **Success criteria**: All 5 nodes execute, final_response field populated
