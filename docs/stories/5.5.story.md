8. Clean, consistent styling across all pages

## Dev Notes

### Navigation Component Structure
```typescript
// src/components/Layout/Navigation.tsx
import { Link, useLocation, useNavigate } from "react-router-dom";

export default function Navigation() {
  const location = useLocation();
  const navigate = useNavigate();

  const handleLogout = () => {
    // Clear auth token
    localStorage.removeItem("auth_token");

    // Optional: Clear other user data
    localStorage.removeItem("chat_messages");

    // Redirect to login
    navigate("/login");
  };

  const isActive = (path: string) => location.pathname === path;

  return (
    <nav className="bg-white border-b border-gray-200">
      <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">
        <div className="flex justify-between items-center h-16">
          {/* Logo or App Name */}
          <div className="flex-shrink-0">
            <h1 className="text-xl font-bold text-gray-900">Career AI</h1>
          </div>

          {/* Navigation Links */}
          <div className="flex space-x-8">
            <Link
              to="/chat"
              className={`px-3 py-2 text-sm font-medium ${
                isActive("/chat")
                  ? "text-blue-600 border-b-2 border-blue-600"
                  : "text-gray-600 hover:text-gray-900"
              }`}
            >
              Chat
            </Link>

            <Link
              to="/upload"
              className={`px-3 py-2 text-sm font-medium ${
                isActive("/upload")
                  ? "text-blue-600 border-b-2 border-blue-600"
                  : "text-gray-600 hover:text-gray-900"
              }`}
            >
              Upload Data
            </Link>

            <button
              onClick={handleLogout}
              className="px-3 py-2 text-sm font-medium text-gray-600 hover:text-gray-900"
            >
              Logout
            </button>
          </div>
        </div>
      </div>
    </nav>
  );
}
```

### Layout Component Pattern
```typescript
// src/components/Layout/Layout.tsx
import Navigation from "./Navigation";

interface LayoutProps {
  children: React.ReactNode;
}

export default function Layout({ children }: LayoutProps) {
  return (
    <div className="min-h-screen bg-gray-50">
      <Navigation />

        {children}
      </main>
    </div>
  );
}
```

### Styling Guidelines
- **Navigation bar**:
  - Background: white
  - Border bottom: light gray
  - Height: 64px (h-16)
  - Shadow: optional subtle shadow
- **Links**:
  - Default: gray-600, hover: gray-900
  - Active: blue-600 with bottom border
  - Font: medium weight, small size
- **Logout button**:
  - Styled as link for consistency
  - Or use button with hover effect
  - Optional: red color to indicate destructive action

### Active Route Highlighting
```typescript
// Method 1: Exact match
const isActive = (path: string) => location.pathname === path;

// Method 2: Starts with (for nested routes)
const isActive = (path: string) => location.pathname.startsWith(path);

// Usage
className={isActive("/chat") ? "active-styles" : "default-styles"}
```

### Logout Flow
1. User clicks "Logout" button
2. Clear JWT token from localStorage
3. Optional: Call backend logout endpoint (if session tracking needed)
4. Clear any cached user data (messages, profile)
5. Redirect to `/login` page
6. Login page should not have navigation bar

### Accessibility
- **Semantic HTML**: Use `<nav>`, `<ul>`, `<li>` for navigation
- **ARIA attributes**: `aria-current="page"` on active link
- **Keyboard navigation**: Tab through links, Enter to activate
- **Focus indicators**: Clear focus ring on keyboard navigation
- **Screen readers**: Announce navigation and active page

### Refactoring Performed

During review, I improved code quality, security, and accessibility:

- **File**: `frontend/src/components/Layout/Navigation.jsx`

  **Change 1: Error Handling for localStorage**
  - **What**: Wrapped localStorage operations in try-catch block
  - **Why**: localStorage can fail in private browsing mode or when quota is exceeded
  - **How**: Added error handling that logs failures but continues with logout, preventing user from being stuck in authenticated state
  - **Impact**: Improved reliability and user experience

  **Change 2: ARIA Attributes for Accessibility**
  - **What**: Added `aria-current="page"` to active navigation links
  - **Why**: Screen readers need semantic indication of current page location
  - **How**: Conditionally set aria-current based on isActive() helper function
  - **Impact**: WCAG 2.1 Level A compliance for navigation landmarks

  **Change 3: Accessible Logout Button**
  - **What**: Added `aria-label="Logout from account"` to logout buttons
  - **Why**: Provides descriptive label for screen reader users
  - **How**: Added aria-label attribute to both desktop and mobile logout buttons
  - **Impact**: Improved accessibility for visually impaired users

  **Change 4: Focus Ring for Mobile**
  - **What**: Added focus ring styles to mobile logout button
  - **Why**: Keyboard navigation users need visible focus indicator
  - **How**: Added `focus:ring-2 focus:ring-blue-500 focus:ring-offset-2 rounded` classes
  - **Impact**: Better keyboard navigation support on mobile devices
