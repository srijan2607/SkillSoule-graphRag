### Environment Variable Documentation

[Source: docs/architecture/tech-stack.md#environment-configuration]

**For README.md "Environment Variables" section:**

| Variable | Description | Where to Obtain | Example |
|----------|-------------|-----------------|---------|
| `NEO4J_URI` | Neo4j database connection URI | Neo4j Aura console (cloud) or local instance | `neo4j+s://xxxxx.databases.neo4j.io` |
| `NEO4J_USERNAME` | Neo4j username | Usually `neo4j` | `neo4j` |
| `NEO4J_PASSWORD` | Neo4j password | Set during Neo4j Aura setup | `your-password-here` |
| `DATABASE_URL` | PostgreSQL connection string | Supabase/Render/Railway console | `postgresql://user:pass@host:5432/db` |
| `OPENROUTER_API_KEY` | OpenRouter API key for LLM | https://openrouter.ai/keys | `sk-or-v1-xxxxx` |
| `OPENROUTER_MODEL` | LLM model to use | OpenRouter docs | `meta-llama/llama-3.3-8b-instruct:free` |
| `EMBEDDING_MODEL` | HuggingFace embedding model | Pre-configured (local) | `sentence-transformers/all-MiniLM-L6-v2` |
| `JWT_SECRET` | Secret key for JWT signing | Generate with `openssl rand -hex 32` | 64-character hex string |
