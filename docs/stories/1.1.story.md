## Dev Notes

### Project Structure Overview

[Source: docs/architecture/source-tree.md#6.1]

The project follows a **monorepo structure** with separate `backend/` and `frontend/` directories:

```
project-root/
├── backend/              # FastAPI backend application
│   ├── app/
│   │   ├── api/          # FastAPI routers
│   │   ├── agents/       # LangGraph agents
│   │   ├── services/     # Business logic layer
│   │   ├── models/       # Pydantic models
│   │   ├── repositories/ # Data access layer
│   │   ├── middleware/   # FastAPI middleware
│   │   └── utils/        # Utility functions
│   ├── prisma/           # Prisma ORM (PostgreSQL)
│   ├── tests/            # Test suite
│   ├── scripts/          # Utility scripts
│   └── docs/             # Backend docs
├── frontend/             # React frontend application
├── data/                 # Sample data directory
├── .env.example          # Environment variables template
├── .gitignore            # Git ignore rules
└── README.md             # Project documentation
```

### Naming Conventions

[Source: docs/architecture/9-coding-standards.md#9.3]

**Files and Directories:**
- Modules: `snake_case` (e.g., `auth_service.py`, `user_repository.py`)
- Directories: `snake_case`, plural for collections (e.g., `api/`, `services/`, `models/`)
- Test files: `test_*.py` (e.g., `test_auth_service.py`)

**All Python packages MUST have `__init__.py` files**
