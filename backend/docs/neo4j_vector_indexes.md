# Neo4j Vector Indexes

## Overview

Vector indexes enable fast similarity search on 384-dimensional embeddings generated by the `sentence-transformers/all-MiniLM-L6-v2` model.

## Index Configuration

- **Dimensions**: 384 (sentence-transformers/all-MiniLM-L6-v2)
- **Similarity Function**: Cosine
- **Auto-Update**: Yes (Neo4j 5.x+)
- **Idempotent Creation**: Uses `IF NOT EXISTS` clause

## Vector Indexes

### 1. Skill Embedding Index

**Name**: `skill_embedding_idx`  
**Node**: `Skill`  
**Property**: `embedding`  
**Purpose**: Find similar skills for skill matching and recommendations

**Usage**:
```cypher
-- Find top 5 skills similar to "Python"
MATCH (s:Skill {name: 'Python'})
CALL db.index.vector.queryNodes('skill_embedding_idx', 5, s.embedding)
YIELD node, score
RETURN node.name, score
ORDER BY score DESC;
```

## Creation Commands

### All Indexes (Recommended)

Run the initial setup script to create all indexes at once:

```bash
cd backend
python scripts/initial_setup.py
```

### Manual Creation

If you need to create indexes manually:

```cypher
-- Skill embedding index
CREATE VECTOR INDEX skill_embedding_idx IF NOT EXISTS
FOR (s:Skill)
ON (s.embedding)
OPTIONS {
  indexConfig: {
    `vector.dimensions`: 384,
    `vector.similarity_function`: 'cosine'
  }
};

-- Job embedding index
```

## Index States

| State | Meaning | Action Required |
|-------|---------|-----------------|
| **ONLINE** | Index is ready and fully populated | None - index is healthy |
| **POPULATING** | Index is being populated with data | Wait for completion (check periodically) |
| **FAILED** | Index creation failed | Rebuild index (see below) |
| **NOT_FOUND** | Index doesn't exist | Create index via setup script |

---

## Rebuild Corrupted Index

**⚠️ WARNING**: Only rebuild if index state is not "ONLINE". Normal embedding updates do NOT require rebuilding (Neo4j 5.x+ auto-updates indexes).

### Via API

```bash
# Rebuild a specific index
curl -X POST http://localhost:8000/admin/vector-indexes/skill_embedding_idx/rebuild \
  -H "Authorization: Bearer $TOKEN"
```

### Manual Rebuild

```cypher
-- Drop corrupted index
DROP INDEX skill_embedding_idx IF EXISTS;

-- Wait 2-3 seconds

-- Recreate index
CREATE VECTOR INDEX skill_embedding_idx IF NOT EXISTS
FOR (s:Skill)
ON (s.embedding)
OPTIONS {
  indexConfig: {
    `vector.dimensions`: 384,
    `vector.similarity_function`: 'cosine'
  }
};

-- Wait for index to populate (check with SHOW INDEXES)
```

## Troubleshooting

### Index Not Populating

**Symptom**: Index stuck in "POPULATING" state for >5 minutes

**Solutions**:
1. Check Neo4j logs for errors
2. Verify nodes have valid embeddings (384-dim float arrays)
3. Check disk space and memory availability
4. Rebuild index if necessary

### Index Creation Failed

**Symptom**: Index creation returns error

**Common Causes**:
1. **Dimension mismatch**: Verify embeddings are 384 dimensions
2. **Invalid property**: Ensure `embedding` property exists and is array of floats
3. **Neo4j version**: Requires Neo4j 5.11+ for vector indexes
4. **Permissions**: Verify Neo4j user has CREATE INDEX permission

**Check embeddings**:
```cypher
-- Verify embedding dimensions
MATCH (s:Skill)
WHERE s.embedding IS NOT NULL
RETURN size(s.embedding) as dim_count, count(*) as node_count;
```

Expected: `dim_count = 384`

## Auto-Update Behavior

**Neo4j 5.x+ automatically updates vector indexes when embeddings change.**

This means:
- ✅ Adding new nodes with embeddings: Index auto-updates
- ✅ Updating existing embeddings: Index auto-updates
- ✅ Deleting nodes with embeddings: Index auto-updates
- ❌ Manual index rebuild: **NOT NEEDED** (only if corrupted)

## Integration with Ingestion

Vector indexes are automatically ensured before every ingestion job:

```python
# In IngestionService (auto-called)
async def start_ingestion(self, ...):
    # Ensure vector indexes exist before ingestion
    await vector_index_service.ensure_vector_indexes_exist()

    # Proceed with ingestion...
```

This guarantees indexes are always available for similarity queries.
