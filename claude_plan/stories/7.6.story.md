# Story 7.6: Frontend NetworkInsightsPanel

## Status

**Ready for Verification**

## Story

**As a** user,
**I want** to see network insights (skill paths, similar jobs, top skills) in a collapsible panel,
**so that** I can explore detailed career data and graph-based recommendations.

## Acceptance Criteria

1. Skill Bridge Paths section shows visual path (skill → skill → skill)
2. Similar Jobs section shows top 5 with match percentages
3. Top Skills section shows centrality-ranked skills
4. Job Fit Analysis shows skills you have vs skills to learn
5. All sections are collapsible (Job Fit default open)
6. Panel only renders when `network_insights` present in response
7. Responsive design (works on mobile)
8. All component tests pass
