## Story

**I want** my queries to be enriched with network metrics (skill paths, centrality, job similarity),
**so that** I get more insightful career guidance based on graph analysis.

3. Skill paths computed (GDS Dijkstra or BFS fallback)
4. Top skills by centrality retrieved from stored metrics
5. Job closeness calculated for queries with user skills
6. All tests pass

```python
# backend/app/agents/nodes/network_enrichment.py

async def network_enrichment_node(state: GraphRAGState) -> GraphRAGState:
    """
    Enrich query with network metrics based on detected intent.

    This node runs after graph_traversal and before context_construction.
    It adds network-based insights like skill paths, centrality rankings,
    and job similarity data.

    Args:
        state: Current graph state with intent and entities

    Returns:
        Updated state with network_enrichment field
    """
    intent = state.get("intent", "")
    intents = state.get("intents", [])
    entities = state.get("entities", [])

    enrichment = {
        "skill_paths": [],
        "top_skills_by_centrality": [],
        "similar_jobs": [],
        "transition_metrics": None,
    }

    # Check if network enrichment is relevant
    network_intents = {"career_transition", "skill_bridge", "skill_importance", "job_similarity"}
    if not (network_intents & set(intents)):
        return {**state, "network_enrichment": enrichment}

    # ... enrichment logic based on intent ...

    return {**state, "network_enrichment": enrichment}
```
